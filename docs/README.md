# CookSmart Docs

Documentação do projeto **CookSmart**, gerada com [Docusaurus](https://docusaurus.io/).

## Desenvolvimento Local

```bash
pnpm start
```

Inicia o servidor de desenvolvimento em `http://localhost:3000`.

## Build

```bash
pnpm build
```

Gera os arquivos estáticos na pasta `build/`.

## Deploy

A documentação é publicada automaticamente no **GitHub Pages** a cada push para a branch `main` via GitHub Actions (`.github/workflows/docs.yml`).

URL pública: `https://observon.github.io/CookSmart/`
